# Lane 2 — The Visit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build screens 6 (the visit), 7 (log-a-reading sheet) and 8 (camera) at `/visits/[id]`, plus the `startVisit` action Lane 3 calls.

**Architecture:** Data access lives in `src/lib/visit-data.ts`: plain async functions that take a `SupabaseClient<Database>`, so the same code runs in server actions and in the integration test against local Supabase. `src/lib/actions/visit.ts` holds thin `"use server"` wrappers that do the auth check, call the data function and return a fresh `VisitSnapshot`. `src/lib/visit.ts` holds pure domain helpers (snapshot types, added-product encoding, missing parts) that Lanes 3 and 4 can import. `/visits/[id]` is a dynamic server page that loads the snapshot and renders one client component, `VisitScreen`, which owns the reading sheet and camera overlays.

**Tech Stack:** Next.js 16.3 App Router, React 19, TypeScript strict, Supabase JS 2.x, Vitest + Testing Library (jsdom).

**Spec:** `docs/superpowers/specs/2026-10-27-app-rebuild-design.md` §6–8; contracts in `docs/superpowers/plans/2026-10-27-app-rebuild.md` (Global Constraints, Route contract, Review Focus, Lane 2). Mockup source: vault `40 Brand/App mockup 2026-10/{Visit,Reading,Camera}.dc.html`.

## Global Constraints

- Every PR: this worktree → PR to `main` → `web (lint · typecheck · build)` + `rls` green → `gh pr merge --squash`. No pushes to `main`/`test`/`prod`; no promotion.
- Never touch `supabase/migrations/` or `src/lib/supabase/types.ts`. Never edit `AppShell`, `TabBar`, `app-tokens.css` (ask the coordinator).
- Copy (D23): never "verified", "tamper-proof", "dispute-grade", "immutable". Green (`--tt-ok`) only for saved/locked/in-range.
- Colours via `--tt-*` tokens inside `.tt-app`; Archivo; tap targets ≥ 44px; contrast ≥ 4.5:1.
- Reading order alkalinity → pH → hardness → chlorine with `READING_FIELDS` / `READING_TARGETS` from `src/lib/readings.ts`; never hard-code a target in a screen.
- Signed-in pages stay dynamic (no `generateStaticParams`, no `force-static`); every route segment has an `error.tsx`.
- No side effects on GET: the draft is created only by `startVisit`.
- Photos: camera only. `Permissions-Policy: camera=()` is set in `next.config.mjs`, so live `getUserMedia` is blocked; the camera overlay uses `<input type="file" accept="image/*" capture="environment">` (spec allows either). No gallery picker anywhere.

## Review Focus

1. **A visit reloaded mid-job** — after each entry type (before photo, found reading, work chip, added product, notes, left reading, after/cover photos, flag) a fresh `loadVisitSnapshot` returns exactly what was saved. Test: `tests/visit.rls.test.ts` › `reload restores every entry type` (Task 2).
2. **"Log it" with untouched rows** — stores null for those rows, never the suggestion. Tests: `tests/visit/reading-sheet.test.tsx` › `untouched rows log as null` (Task 3) and `tests/visit.rls.test.ts` › `logReading stores null for unset rows` (Task 2).
3. **Double-tap on Start visit** — returns the existing open draft for that tub, never a second draft. Test: `startVisit is idempotent per tub` (Task 1).
4. **Finish with nothing logged** — locks anyway; snapshot reports every part missing (partial). Test: `finish locks an empty visit as partial` (Task 2).
5. **First visit to a tub (no history)** — suggestions are absent (rows show "—"), no "Last visit" photo, no NaN. Test: `no previous visit → no suggestions` (Task 3) and snapshot `previous === null` (Task 1).

```ts
export type PhotoKind = "before" | "after" | "cover";
export const PHOTO_KINDS: Record<PhotoKind, { phase: "before" | "after"; slot: "full_frame" | "cover"; label: string }>;
// before → before/full_frame "Before"; after → after/full_frame "After · full tub"; cover → after/cover "Cover on"
export function photoKindOf(phase: string, slot: string): PhotoKind | null;
export type ReadingValues = Record<ReadingField, number | null>;
export type AddedProduct = { product: string; amount: string };
export type VisitPhoto = { id: string; kind: PhotoKind; storagePath: string; capturedAt: string | null };
export type VisitSnapshot = {
  visitId: string; propertyId: string; propertyName: string;
  status: "draft" | "submitted_locked"; openedAt: string;
  photos: VisitPhoto[];                       // at most one per kind
  found: ReadingValues | null; foundAt: string | null;
  left: ReadingValues | null;  leftAt: string | null;
  work: CleaningStepCode[]; added: AddedProduct[]; notes: string;
  flag: string | null;                        // Task 5; null until owner_flag lands
  previous: { visitId: string; visitedOn: string; found: ReadingValues | null;
              photos: VisitPhoto[] } | null;  // last LOCKED visit of this tub
};
export const WORK_CHIPS: { code: CleaningStepCode; label: string }[];
// mockup order + labels: filters_cleaned "Cleaned filter", wiped "Wiped down",
// filter_replaced "Replaced filter", drained_refilled "Drained & refilled",
// water_topped "Topped off", cover_cleaned "Cleaned cover"
export function encodeAdded(a: AddedProduct): string;   // "pH down · 2 oz" (" · " joins; amount may be "")
export function decodeAdded(s: string): AddedProduct;   // inverse; legacy codes → { product: s, amount: "" }
export type MissingPart = "before photo" | "reading as found" | "reading as left" | "after photo" | "cover photo";
export function missingParts(s: Pick<VisitSnapshot, "photos" | "found" | "left">): MissingPart[];
export const isPartial: (s: Pick<VisitSnapshot, "photos" | "found" | "left">) => boolean;

// src/lib/visit-data.ts   (Db = SupabaseClient<Database>)
export async function findOpenDraft(db: Db, propertyId: string, userId: string): Promise<string | null>;
export async function createDraft(db: Db, propertyId: string, userId: string): Promise<string>;
export async function loadVisitSnapshot(db: Db, visitId: string): Promise<VisitSnapshot>; // throws "Visit not found"

// src/lib/actions/visit.ts
export async function startVisit(propertyId: string): Promise<{ visitId: string }>;
export async function getVisitSnapshot(visitId: string): Promise<VisitSnapshot>;
```
`createDraft` inserts `turnover { property_id, submitter_id, status: "draft", share_token: crypto.randomUUID(), cleaning_steps: [] }`. `openedAt` = `turnover.created_at`.
